# SQL Projects

A collection of **SQL projects** completed through learning, practice, and personal projects.

## About

This repository contains SQL exercises and projects focused on **data analysis, business intelligence, and database querying**.

The goal is to practice SQL concepts on real-world datasets and turn raw data into meaningful insights.

## Topics Covered

- Data exploration and analysis
- `SELECT`, `WHERE`, `ORDER BY`
- `GROUP BY` and aggregate functions
- `JOIN` and relational data
- Subqueries and correlated subqueries
- Common Table Expressions (`CTE`)
- `UNION` and `UNION ALL`
- Window functions
- Customer and product analysis
- Business metrics and KPIs
- Data-driven business insights
